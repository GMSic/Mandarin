Connect ChatGPT (OpenAI)

This app talks to OpenAI directly from your browser. It needs an API key.
How do I get a key?
  1. Open platform.openai.com/api-keys and sign in with your OpenAI / ChatGPT login.
  2. Under Billing, add a few dollars of credit and set a low monthly limit. A ChatGPT Plus subscription does not include API usage, it is billed separately.
  3. Tap "Create new secret key", copy it right away (it is shown once), and paste it above.
The key is saved only in this browser on this device. It is not in the code or the GitHub repo.
